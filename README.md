# Toy Bloom

Modern toy-store frontend built with Next.js 14 (App Router), TypeScript, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

The brand name is centralized in `lib/constants.ts` as `SITE_NAME` (`Toy Bloom`). Cart and wishlist persist in the browser only; checkout is a mock flow.
